Help test the RF scanner BETA

Find surveillance cameras by the wifi they broadcast. No hardware, no money, just your phone.

🔒 What it does, and what it never does

Flock and other ALPR cameras broadcast a wifi name. This scanner watches for those names and only those. Every other network your phone sees — homes, other phones, shops — is counted and thrown away instantly, never shown, never saved, never sent. Same rule SparrowMap uses for licence plates: the private side is destroyed on your device.

It uploads nothing on its own. You look at what it flags and send it to us by hand. Nothing hits the map without a person reviewing it.

📱 What you need

  • An Android phone (iPhone can't scan wifi like this — Android only for now).
  • Termux and Termux:API — both free from F-Droid (not the Play Store versions, they're outdated).

▶️ Setup (one time, ~2 minutes)

Open Termux and paste:

pkg install -y python termux-api
curl -O https://map.sparrowmap.com/rf/phone_scan.py

Then install the Termux:API app from F-Droid if you haven't (it's what lets the script read wifi).

🚗 Run it

python phone_scan.py            # one scan, right where you are
python phone_scan.py --watch   # keep scanning while you walk or drive

Best test: drive or walk past a spot you know has a Flock or ALPR camera (intersections, town entrances, parking lots). If it broadcasts wifi, you'll see a 🚨 SURVEILLANCE line.

When you're done, it prints a block starting --- copy everything below ---. Copy that and send it to us, along with roughly where you were (a cross street is plenty).

⚠️ What we're actually testing

  • Whether real Flock/ALPR cameras show up at all, and what names they use — that's the data we need to make this reliable.
  • Phones only see cameras that broadcast a name. Silent devices and deeper Bluetooth need the Raspberry Pi version (coming later). Broadcast is plenty to prove it works.
  • False alarms are fine and useful — send them too. Nothing you send goes public without us reviewing it.

📤 Sending results (phone)

For the phone beta, just paste the copied block to us (DM or email) with a rough location. It's reviewed before anything goes on the map.

🖥️ Raspberry Pi (auto-upload)

If you have a Pi (or any Linux box) it can scan and upload on its own, no copy-paste. Same rule: only surveillance devices leave the box, every private network is dropped there. Uploads land in a review pen — nothing goes on the public map without a person confirming it.

1. Get the scanner:

sudo apt install -y network-manager python3
curl -O https://map.sparrowmap.com/rf/rf_scan.py

2. Enroll once to get a node id + token (save the token, shown once):

curl -X POST https://map.sparrowmap.com/api/enroll \
  -H "Content-Type: application/json" \
  -d '{"name":"My RF Pi","lat":XX.XXXX,"lon":-YY.YYYY,"kind":"rf"}'

3. Run it (loops, scans, uploads surveillance devices only):

python3 rf_scan.py --post --node n_YOURID --token YOURTOKEN

Mount it in a vehicle or a window overlooking a road. A GPS dongle is optional now (position is added in the next version); for a fixed spot the enroll location is enough. The monitor-mode + Bluetooth upgrade (an Alfa adapter) comes later — plain wifi scanning already catches broadcasting cameras.

🔜 What's next

Once field tests confirm the scanner reliably spots real cameras, we turn on a dedicated surveillance map layer so confirmed devices show up alongside the vehicle map — always behind the same human review.

Open source, free, government and surveillance hardware only. Your neighbours and your own devices are destroyed at the edge and never leave your phone. That's the whole point.
